# M30 状态页与 SLA 报表

M30 把探测结果变成对外可展示的**状态页**和面向内部的**SLA 报表**：状态页按租户配置公开（凭不可猜测的链接访问），展示探测目标组的当前状态、可用率与进行中的事件；SLA 报表在管理台按目标组查可用率、平均/P95 延迟、失败次数与事件数。不改探测执行、判定与通知语义。

## 目标与依赖

操作者可以：

1. 新建状态页：标题、描述、启停、选择要展示的目标组（一个或多个）、生成并复制公开链接。
2. 用公开链接访问状态页（无需登录），看到各目标组的当前状态（正常/降级/故障）、24 小时 / 7 天 / 30 天可用率、最近一次检查时间，以及进行中与最近结束的事件。
3. 在管理台「探测 SLA」页按目标组与日期范围（最多 30 天）查看可用率、检查次数、失败次数、平均延迟、P95 延迟、事件数与按天的可用率明细。

依赖：M18 / M26 / M27（探测目标组、结果、事件）、M4（事件与通知，可选）、M1（租户与权限）。

## 数据模型

### `status_pages`（新表）

| 字段 | 说明 |
| --- | --- |
| `uid` / `namespace_uid` / `name` | 租户内未删除记录唯一 |
| `title` / `description` | 对外展示的标题与描述 |
| `token` | 32 位随机字符串，全局唯一，公开访问凭证；重新生成后旧链接立即失效 |
| `status` | `ACTIVE` / `DISABLED`，默认 `ACTIVE` |
| `target_group_uids` | 要展示的目标组 UID JSON 数组，至少一个 |
| `created_by` | 创建人 |

### `probe_sla_daily`（新表）

按「目标组 × 目标 × 自然日」预聚合探测结果，保证原始结果只保留 7 天时 SLA 仍能查询 30 天。

| 字段 | 说明 |
| --- | --- |
| `namespace_uid` / `group_uid` / `target_uid` | 维度，唯一键加上 `day` |
| `day` | 本地自然日（按租户时区暂无概念，统一 UTC 日，页面按 UTC 日展示并注明） |
| `checks` / `ok_checks` / `failed_checks` | 检查次数与成功/失败次数 |
| `total_duration_ms` / `max_duration_ms` | 延迟累计与最大值，用于平均延迟与近似 P95 |

聚合任务由 `alioth` 调度器每小时执行（锁 `alioth:lock:schedule:probe-sla`）：重算昨天与今天已结束的槽位并 upsert；探测结果清理任务先补跑聚合再删除原始结果，避免丢数据。

## 接口

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| `GET/POST` | `/v1/status-pages` | `status_page:read` / `status_page:write` |
| `GET/PUT/DELETE` | `/v1/status-pages/{uid}` | 读 / 写 / `status_page:delete` |
| `PUT` | `/v1/status-pages/{uid}/status` | `status_page:write` |
| `POST` | `/v1/status-pages/{uid}/token` | `status_page:write`（重新生成链接） |
| `GET` | `/v1/probe-sla` | `probe_sla:read` |
| `GET` | `/v1/status/{token}` | 公开，无需登录与租户头 |

公开接口只返回展示必需字段：页面标题/描述、组件名（目标组名）、组件状态、可用率、最近检查时间、事件标题与起止时间。不返回目标地址、标签、数据源、规则、租户与用户信息。

新增能力：`status_page` 与 `probe_sla`（都在探测模块下，菜单「状态页」「探测 SLA」），权限 `status_page:*`、`probe_sla:read` 与对应菜单权限。两者进入基础套餐，升级时基础套餐租户自动补上。

### 公开接口的鉴权与安全

- `/v1/status/{token}` 从 HTTP 中间件里排除 JWT 与租户校验，只按 token 查询启用中的状态页；token 无效、页面停用或租户停用/归档时返回 404，不区分原因。
- 公开响应不设置缓存（`Cache-Control: no-store`），不做跨租户聚合；按 token 限流（同一 IP 每分钟 120 次）由 nginx 或服务端内存计数实现，超限返回 429。
- 状态页 token 只读；删除状态页或停用后链接立即失效。

## 状态与可用率语义

- 目标组当前状态：该组内启用目标的最新一次探测结果全部成功为「正常」；任一失败为「故障」；没有结果或结果超过 3 个探测周期未更新为「未知」。
- 可用率 = 成功检查次数 / 总检查次数，按目标组内所有启用目标合并计算；无数据显示「—」，不做除零。
- 进行中事件取该目标组当前 FIRING 的探测事件（`probe_kind` 非空），按目标组名聚合；事件标题使用事件摘要，不展示目标地址。最近结束事件取最近 10 条已恢复事件。
- SLA 报表按天返回 `checks / okChecks / failedChecks / availability / avgLatencyMs`；P95 由原始结果计算（7 天内）或由日聚合的 `max_duration_ms` 近似（超出 7 天时在页面上注明「近似值」）。

## Web

- 新增管理页面「状态页」（探测菜单）：列表（名称、目标组数量、状态、公开链接复制、最近更新时间）、新建/编辑对话框（名称、标题、描述、目标组多选）、重新生成链接（二次确认）、启停与删除；页面提示「链接即凭证，分享给外部人员前请确认内容」。
- 新增管理页面「探测 SLA」（探测菜单）：目标组与日期范围（默认 7 天，最多 30 天）筛选，汇总卡片（可用率、检查次数、失败次数、平均延迟、P95）与按天明细表；空数据显示引导。
- 新增公开页面 `/status/:token`（不经过登录壳与侧边栏，独立布局，跟随系统主题）：状态页标题/描述、整体状态横幅、组件列表（状态徽标、可用率 24h/7d/30d、最近检查）、进行中与最近事件；事件状态用文字 + 颜色双重表达。
- i18n 中英文、错误码映射、权限判断按现有惯例；公开页面不引入需要登录的接口。

## 验收

1. 创建状态页并复制链接，未登录浏览器打开 `/status/{token}` 成功展示标题、组件状态与可用率；停用后同一链接返回 404。
2. 让一个目标组内目标探测失败：状态页当前状态变为故障，进行中事件出现；恢复后状态回到正常，事件移入最近结束列表。
3. 重新生成 token 后旧链接 404，新链接正常；公开接口不返回目标地址、标签与租户身份。
4. 状态页选择的目标组被删除或停用后，公开页不再展示该组件，不报错。
5. SLA 页按目标组与 7 天范围返回汇总与按天明细；跨 7 天以上区间使用日聚合，页面标明近似 P95；选择今天之后的日期被拒绝，超过 30 天的区间服务端返回参数错误。
6. 日聚合任务重跑幂等：同一 `(group,target,day)` 只有一行，`checks` 不重复累加；聚合先于探测结果清理执行。
7. 能力开关：未开通 `status_page` / `probe_sla` 时对应页面与接口 403；基础套餐租户升级后自动获得两个菜单。
8. `make vet` / `make lint` / `make test`、Web typecheck/lint/build 通过；浏览器验证管理页 CRUD、公开页与 SLA 筛选。

## 不做什么

- 不做自定义状态页域名与 CSS、不做订阅通知（邮件/短信订阅状态更新）、不做多语言状态页内容编辑。
- 不做基于目标维度的逐个目标公开展示（按目标组聚合）。
- 不改探测结果保留策略本身；日聚合先于清理写入，原始结果仍按 7 天/200 条保留。

## 风险

- 公开接口是新攻击面：只接受 token、返回字段白名单、限流与 no-store 缓存头必须同时落地。
- P95 在超过 7 天的区间用最大值近似会偏高，页面必须显式标注，不能用近似值冒充精确分位数。
- 时区：第一版按 UTC 自然日聚合并展示；租户时区的日边界留给后续里程碑。
