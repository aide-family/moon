# Brand icons

Product marks used by datasource drivers and notification channels. Each file keeps the
original single-color glyph and is recolored with the product's brand color.

| File | Product | Source | License |
| --- | --- | --- | --- |
| `dingtalk.svg` | DingTalk | [Ant Design Icons](https://github.com/ant-design/ant-design-icons) `dingtalk` | MIT |
| `wecom.svg` | WeCom (企业微信) | [Ant Design Icons](https://github.com/ant-design/ant-design-icons) `wechat-work-outlined` | MIT |
| `feishu.svg` | Feishu / Lark (飞书) | [IconPark](https://github.com/bytedance/IconPark) `lark` | Apache-2.0 |

The other files in this directory are from [Simple Icons](https://simpleicons.org) (CC0-1.0),
except `vlogs.svg`, which is drawn for this project.
